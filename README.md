````markdown
# Система управления умными светофорами

## Описание системы

Это программная система моделирования транспортных потоков и алгоритмов управления светофорами. Она позволяет:

- Сравнивать эффективность традиционных и умных светофоров
- Визуализировать состояние перекрестка в реальном времени
- Анализировать метрики трафика (время ожидания, длина очередей)
- Тестировать различные сценарии трафика

## Структура проекта

| Файл                             | Назначение                                                  |
| -------------------------------- | ----------------------------------------------------------- |
| **traffic_model.py**             | Модель транспортного потока на четырехстороннем перекрестке |
| **traditional_traffic_light.py** | Традиционный светофор с фиксированными фазами               |
| **smart_traffic_light.py**       | Умный светофор с адаптивным управлением                     |
| **visualization.py**             | Визуализация модели с использованием matplotlib             |
| **comparison.py**                | Сравнение эффективности алгоритмов                          |
| **main.py**                      | Главный модуль с интерфейсом командной строки               |
| **test_system.py**               | Тестирование компонентов системы                            |
| **simple_traffic_system.py**     | Самодостаточный пример работы системы                       |

## Требования к установке

- Python 3.8 или выше
- Библиотеки:
  - numpy
  - matplotlib
  - pandas
  - pillow (для сохранения анимаций, опционально)
  - ffmpeg (для сохранения видео, опционально)

### Установка зависимостей

```bash
pip install numpy matplotlib pandas pillow
```
````

## Как запускать систему

### Базовый запуск

```bash
python main.py
```

### С параметрами командной строки

```bash
# Запуск с традиционным алгоритмом и визуализацией
python main.py -a traditional -v

# Умный алгоритм с длительностью 1000 шагов
python main.py -a smart -d 1000

# Полное сравнение алгоритмов
python main.py --compare
```

### Запуск тестов

```bash
python test_system.py
```

### Запуск визуализации

```bash
# Для базовой визуализации
python visualization.py

# Сохранение анимации
python visualization.py --output simulation.mp4
```

### Примеры запуска


## Как проверить правильность работы

### Запуск тестов

```bash
python test_system.py
```

Успешное прохождение всех тестов означает, что компоненты системы работают корректно.

### Проверка выводимой статистики

После запуска симуляции система выводит:

- Среднее время ожидания
- Максимальное время ожидания
- Количество пропущенных автомобилей
- Среднюю длину очереди
- Процент времени с пустыми очередями

### Анализ визуализации

При запуске с флагом `-v` вы увидите:

1. Схему перекрестка с автомобилями и светофорами
2. График среднего времени ожидания
3. Гистограмму длин очередей
4. Текстовую статистику

## Возможные проблемы и их решения

### Ошибка импорта

**Ошибка**: `ModuleNotFoundError: No module named 'numpy'`  
**Решение**: Убедитесь, что вы установили все зависимости: `pip install numpy matplotlib pandas`

### Проблемы с визуализацией

**Ошибка**: `ImportError: No module named 'matplotlib'`  
**Решение**: Установите matplotlib: `pip install matplotlib`

### Проблемы с анимацией

**Ошибка**: `RuntimeError: Requested MovieWriter (ffmpeg) not available`  
**Решение**: Установите ffmpeg: см. раздел "Установка зависимостей"

### Тесты не проходят

**Ошибка**: Один или несколько тестов завершаются неудачей  
**Решение**: Убедитесь, что вы не вносили изменений в исходный код. Если проблема сохраняется, откройте issue на GitHub.

### Графики сравнения

Генерируются два графика:

1. **Среднее время ожидания**: Более короткие столбцы указывают на лучшую производительность
2. **Количество пропущенных автомобилей**: Более высокие столбцы указывают на более высокую пропускную способность

## Интерпретация результатов

### Основные метрики

| Метрика                             | Описание                                                  | Идеальное значение |
| ----------------------------------- | --------------------------------------------------------- | ------------------ |
| Среднее время ожидания              | Среднее время ожидания автомобиля в очереди               | Минимальное        |
| Максимальное время ожидания         | Максимальное время ожидания за весь период                | Минимальное        |
| Количество пропущенных автомобилей  | Общее количество автомобилей, прошедших через перекресток | Максимальное       |
| Средняя длина очереди               | Среднее количество автомобилей в очереди                  | Минимальное        |
| Процент времени с пустыми очередями | Доля времени, когда нет автомобилей в очереди             | Максимальное       |

### Примеры сценариев

1. **Час пик N-S**  
   Умный светофор должен показать на 20-30% меньшее время ожидания по сравнению с традиционным алгоритмом

2. **Равномерный поток**  
   Оба алгоритма показывают схожие результаты, так как нагрузка равномерна

3. **Высокая нагрузка**  
   Умный светофор должен пропустить больше автомобилей благодаря адаптивной настройке фаз
